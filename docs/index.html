How to install

First launch is unsigned, so your OS will ask you to confirm. Here's how.

Windows
  1. Download the .zip build kit and unzip it.
  2. Double-click build_windows.bat. If SmartScreen appears, click More info → Run anyway.
  3. When it finishes, the .msi is in the dist folder — run it to install, then launch from the Start Menu.
macOS
  1. Open the .dmg and drag the app into Applications.
  2. Double-click Launch CircuitRunners Outreach.command inside the DMG to bypass the first-time security prompt and open immediately.
  3. Alternatively: right-click the app → Open, then confirm (or System Settings → Privacy & Security → Open Anyway).

FAQ

Is it safe to install?
Yes. The app runs locally and only creates drafts in your own Gmail. Verify each download against the SHA-256 checksum on its card.
Does it send email automatically?
No. It only writes drafts to your Gmail Drafts folder. Nothing is sent unless you review and send it yourself.
What does it access?
It requests only the Gmail draft-creation scope (gmail.compose) and CCs the team coordinators on every draft. Your credentials, token, photos, and settings stay on your machine.
